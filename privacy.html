YOUR INFORMATION

Privacy overview.

This is a preliminary privacy overview, not a final privacy notice. Complete the legal review before collecting real user data publicly.

Data collected in the MVP

The account setup asks for a name, email address, password, date of birth and city. The backend stores the password only as a salted password hash.

Sessions

Authentication uses an HttpOnly session cookie; the raw session token is not stored in the database.

How data is used

Account details are used to provide and secure the service. Public profile and matching features will have separate privacy controls in later milestones.

Your controls

Account export, deletion requests, retention periods, verification providers and support contact details need to be implemented and documented before public launch.
