# Date Concierge — next milestones

1. Approve login and registration design on desktop and mobile.
2. Choose a backend architecture and database separately from the static UI.
3. Implement registration/login endpoints, server-side validation, password hashing, sessions, email verification and rate limiting.
4. Connect the forms to real endpoints only after the backend is available; never store raw passwords in browser storage.
5. Add profile and relationship-preference onboarding.
6. Add verified profile workflows, mutual-consent introductions and concierge date coordination.
7. Add subscriptions and an auditable credit/refund ledger only after payment and refund policy decisions are finalized.
8. Complete security, privacy, safety, refund/cancellation and end-to-end tests before a public launch.

## Current status

Only UI and browser-side demo validation are implemented. Items 2–8 are not implemented and must not be presented as available functionality.
