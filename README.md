# Date Concierge Dashboard UI v1.0

Responsive member dashboard for mobile browser and desktop/laptop.

- Dark plum and rose visual style aligned with the approved designs.
- Desktop sidebar + top search/action bar + main content and right rail.
- Mobile compact top bar, two-column live metric cards, horizontally scrollable recommendations, and fixed bottom navigation.
- Uses existing authentication, profile, discovery, and introduction APIs.
- Does not fabricate match/member/message/profile-view statistics.
- Membership prices displayed: Date Plus ₹799/month and Private Concierge ₹1,499/month. Checkout is not active.
